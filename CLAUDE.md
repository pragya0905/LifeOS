# LifeOS

Before working on any frontend page or component, read [DESIGN.md](DESIGN.md) — it holds the
standing design/product rules from the user's own feedback (interaction patterns, status
color/labeling, layout density, date navigation, data-integrity rules, and the per-page
process: mockups first, real-data-scale testing, one commit per page). Follow it exactly;
treat it as binding, not advisory.
